Java provides a variety of built-in string methods in the `String` class, which are incredibly useful for manipulating and processing strings. Here’s a rundown of the most commonly used methods:

### 1. **Basic String Operations**
   - `length()`: Returns the length of the string.
   - `charAt(int index)`: Returns the character at the specified index.
   - `substring(int beginIndex)`: Returns a new string starting from `beginIndex` to the end of the string.
   - `substring(int beginIndex, int endIndex)`: Returns a substring from `beginIndex` to `endIndex - 1`.
   - `indexOf(String str)`: Returns the index of the first occurrence of the specified substring.
   - `lastIndexOf(String str)`: Returns the index of the last occurrence of the specified substring.
   - `contains(CharSequence s)`: Checks if the string contains the specified sequence.
   - `isEmpty()`: Checks if the string is empty.
   - `isBlank()`: Checks if the string is empty or contains only white space (Java 11+).

### 2. **String Comparison**
   - `equals(Object anObject)`: Compares two strings for content equality.
   - `equalsIgnoreCase(String anotherString)`: Compares two strings, ignoring case considerations.
   - `compareTo(String anotherString)`: Compares two strings lexicographically.
   - `compareToIgnoreCase(String str)`: Compares two strings lexicographically, ignoring case.

### 3. **String Modification**
   - `toLowerCase()`: Converts all characters in the string to lowercase.
   - `toUpperCase()`: Converts all characters in the string to uppercase.
   - `trim()`: Removes leading and trailing whitespace.
   - `replace(char oldChar, char newChar)`: Replaces all occurrences of a specified character with a new character.
   - `replace(CharSequence target, CharSequence replacement)`: Replaces each substring that matches the target sequence.
   - `replaceAll(String regex, String replacement)`: Replaces each substring that matches the given regular expression with the specified replacement.
   - `replaceFirst(String regex, String replacement)`: Replaces the first substring that matches the given regex with the replacement.
   - `strip()`: Removes leading and trailing whitespace (like `trim`, but more Unicode-aware).
   - `stripLeading()`: Removes leading whitespace (Java 11+).
   - `stripTrailing()`: Removes trailing whitespace (Java 11+).

### 4. **Splitting and Joining**
   - `split(String regex)`: Splits the string around matches of the given regular expression.
   - `split(String regex, int limit)`: Splits the string around matches of the regex with a maximum number of splits.
   - `join(CharSequence delimiter, CharSequence... elements)`: Joins multiple strings with a specified delimiter.

### 5. **Checking Content**
   - `startsWith(String prefix)`: Checks if the string starts with the specified prefix.
   - `startsWith(String prefix, int offset)`: Checks if the substring beginning at the specified index starts with the specified prefix.
   - `endsWith(String suffix)`: Checks if the string ends with the specified suffix.
   - `matches(String regex)`: Checks if the string matches the given regular expression.
   - `contains(CharSequence s)`: Checks if the string contains the specified sequence of characters.

### 6. **Conversions**
   - `toCharArray()`: Converts the string to a character array.
   - `getBytes()`: Converts the string to a byte array.
   - `valueOf(...)`: Converts different types (such as `int`, `double`, `char`, etc.) to strings.
   - `intern()`: Returns a canonical representation for the string, which is stored in the string pool.

### 7. **String Formatting**
   - `format(String format, Object... args)`: Returns a formatted string using the specified format string and arguments (like `printf`).
   - `String.format(Locale l, String format, Object... args)`: Returns a formatted string with locale-specific settings.

### 8. **Advanced Methods**
   - `hashCode()`: Returns a hash code for the string.
   - `concat(String str)`: Concatenates the specified string to the end of this string.
   - `codePointAt(int index)`: Returns the Unicode code point at the specified index.
   - `codePointBefore(int index)`: Returns the Unicode code point before the specified index.
   - `codePoints()`: Returns an IntStream of code points in the string (Java 8+).
   - `repeat(int count)`: Returns a new string which is the current string repeated `count` times (Java 11+).

These methods cover a range of functionalities to work with strings, from basic manipulation to advanced regex and formatting. You can use combinations of these to perform powerful string operations in Java.
